## Highlights ⭐️

* **Initial release of jspassgen**: launches the utility for generating cryptographically secure passwords and passphrases.
* **Configurable entropy**: supports strong, base64, and memorable password generation with custom length, iteration count, and chunk separators.
* **Interactive CLI and programmatic API**: provides a command-line interface with customizable options alongside an importable Node.js module.
