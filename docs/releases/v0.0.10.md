## Highlights ⭐️

* **Hexagonal architecture**: introduces platform-agnostic `@password-generator/core` package with zero runtime dependencies.
* **Web UI demo**: provides browser-based password generation using the identical core engine via Port/Adapter patterns.
* **Parity verification**: establishes cross-platform parity tests and performance benchmarks for generation and entropy calculation.
