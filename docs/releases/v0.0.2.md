## Highlights ⭐️

* **Phonetic password utilities**: adds random consonant, vowel, and syllable generators for pronounceable passwords.
* **String case conversions**: provides toSnakeCase, toTitleCase, and toCamelCase helper utilities.
* **ECMAScript 6 modernization**: introduces Babel transpilation and expanded Chai unit test assertions.
